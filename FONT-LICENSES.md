# Website typography

This website uses **D-DIN Regular** and **D-DIN Bold** for its site typography.

- Typeface copyright: Copyright © 2017 Datto Inc.
- Typeface design: Charles Nix (Monotype).
- License: SIL Open Font License 1.1 (OFL).
- Upstream font files and license information: https://github.com/amcchord/datto-d-din
- Runtime font delivery: jsDelivr (`cdn.jsdelivr.net`)

The HTML loads the two WOFF2 font files at runtime. The website therefore needs an internet connection to display the exact D-DIN font; when offline, the CSS falls back to Helvetica/Arial. The original site images, logos, favicon files, and metadata are preserved.
